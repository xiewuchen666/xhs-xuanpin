## 2. 已确认的页面骨架

### 2.1 桌面工作台

默认布局：

- 顶部：产品标题、单品监控 / 店铺监控 / 选品中心、采集状态与全局频率。
- 工作台不保留 Windows 默认系统标题栏；最小化 / 最大化 / 关闭统一下移到自定义顶栏右侧，自定义顶栏同时承担窗口拖动、双击最大化 / 还原与窗口控制。
- 顶部导航属于**全局工作台外壳**，必须横跨左侧手机区与右侧数据区；不得只放在右侧 WebView 内。
- 单品监控 / 店铺监控 / 选品中心这一组导航的起点必须与右侧数据工作区左边界对齐，而不是紧跟品牌标题。
- 左侧：小红书 Android 手机预览区。
- 中间：手机区收起 / 展开控制。
- 右侧：数据工作区。
- 右侧根据窗口宽度扩展，不额外增加传统后台侧边栏。

### 2.2 手机区

- 保持手机竖屏比例，不允许变形拉伸。
- 商品详情页显示“加入监控 / 加入选品中心”快捷操作。
- 手机预览底部固定保留“已识别商品详情页”操作条；识别成功后展示当前商品标题与价格摘要，并提供两项快捷操作。
- 非商品详情页保留“加入监控 / 加入选品中心”两个快捷操作的位置，但按钮置灰禁用；不要隐藏，避免底部操作区结构忽隐忽现。
- 提供“收起手机”控制。
- 手机区默认随工作台窗口宽度响应式变化，并始终保持手机竖屏比例。
- 手机区与右侧工作区之间提供轻量可拖拽分隔线，允许人工调整手机预览宽度；当前 V1 宽度约束为 400–680px。
- 人工调整后的手机区宽度在“收起 → 展开”后恢复，不跳回固定宽度。
- 收起时手机区向左隐藏，右侧数据工作区占满可用宽度。
- 收起不停止 Android、不退出账号、不改变小红书当前页面。
- 收起状态保留一个轻量“展开手机预览”入口。

### 2.3 右侧三个核心页

1. 单品监控
2. 店铺监控
3. 选品中心

三页必须共用相同的视觉系统、表格密度、筛选控件和状态组件，不为不同页面随意创造新的视觉风格。

## 3. 已确认的视觉基线

### 3.1 色彩

品牌红：

- 主红：`#FF2442`
- Hover：`#F20D32`
- Pressed：`#D90B2C`
- 柔红背景：`#FFF1F3`
- 柔红边框：`#FFD6DC`

文字：

- 主文字：`#1A1A1A`
- 次级文字：`#595959`
- 辅助文字：`#666666`
- 禁止将 `#999999 / #AAAAAA` 用作主要正文、表头、说明信息或重要辅助信息。

表面：

- 主画布：`#FFFFFF`
- 分组 / 搜索背景：`#F7F7F7`
- 次级区域：`#FAFAFA`
- 分割线：`#EDEDED`
- 强边框：`#DDDDDD`

语义色：

- 成功：`#1FA663`
- 警告：`#E89A19`
- 错误：`#E5484D`
- 信息：`#3E7BFA`

品牌红不承担所有错误 / 警告语义。

### 3.2 可读性

- 灰色文字必须满足可读性优先原则，正文和重要辅助信息目标满足 WCAG 4.5:1 对比度。
- 中文正文、辅助说明绝不低于 **12px**。
- 常用正文：13–14px。
- 表头：12px / 600。
- 页面标题：22px / 500。
- 模块标题：16px / 500。
- 正文：13–14px / 400–500。
- 关键数字：允许 600。
- 标题不使用大面积 700/800 粗黑字重，避免视觉疲劳。

推荐字体栈：

```css
font-family:
  "Microsoft YaHei UI",
  "Microsoft YaHei",
  "PingFang SC",
  "Noto Sans CJK SC",
  "Segoe UI",
  system-ui,
  sans-serif;
```

### 3.3 圆角与阴影

- 按钮 / 输入框：6px。
- 普通卡片：8px。
- 较大容器：10–12px。
- 搜索框 / 状态标签：胶囊圆角。
- 默认不使用厚重阴影。
- 只有手机预览、浮层、菜单允许轻量阴影。

## 4. 信息密度

右侧数据区定位为**长时间人工选品工作台**，不是营销展示页。

### 4.1 商品表格

建议行高：72–80px。

单品监控与选品中心默认列：

- 商品 / 店铺
- 当前价
- 累计销量
- 今日新增
- 近24小时新增
- 最近区间
- 最近更新
- 状态
- 操作

商品信息：

- 主图 48–52px。
- 商品名 13–14px / 500。
- 店铺名 12px / #666666。
- 数字对齐，优先 tabular numerals。

### 4.2 店铺监控

店铺一行汇总，点击展开商品明细。

汇总字段：

- 店铺信息
- 已监控商品数
- 今日新增汇总
- 近24小时新增汇总
- 最近更新时间
- 数据状态
- 展开操作

## 5. 主要组件

### 5.1 顶部导航

- 当前 Tab 使用深色文字 + 2px 品牌红下划线。
- 未选中 Tab 使用 #595959 / #666666。
- 不将三个 Tab 做成大面积红色按钮。

### 5.2 主按钮

高优先级：

- “加入选品中心”
- “立即采集本页”

使用品牌红实心。

普通操作：

- “加入监控”
- “采集”
- “设置”
- 筛选器

使用白底 + 中性边框。

### 5.3 状态

- 正常：绿色浅底 + 绿色文字。
- 需更新：橙色浅底 + 橙色文字。
- 状态必须同时有文字，不只依赖颜色。

### 5.4 导出

单品监控、店铺监控、选品中心都提供统一“导出”入口。

点击后显示：

- 导出 Excel
- 导出 CSV

导出入口为次级操作，不抢占主操作视觉优先级。

## 6. 页面级已确认约定

### 6.1 单品监控

顶部：

- 页面标题 + 商品数量
- 4 个统计卡
- 搜索 / 店铺筛选 / 排序
- 导出
- 立即采集本页
- 设置

表格强调：

- 单品监控、店铺监控展开明细、选品中心中的商品标题统一为可点击链接；点击后使用系统默认浏览器打开该商品的小红书原始商品 URL，不进入工作台内部详情页。
- 今日新增、近24h新增使用成功绿色。
- 最近区间保持主文字色，不通过彩色制造噪音。
- 每行“操作”列默认只显示轻量三点入口 `···`，避免长列表出现大量按钮噪音。
- 点击三点后使用项目自定义轻量操作浮层，不照搬第三方产品样式。
- 浮层包含：立即采集、暂停 / 恢复监控、加入选品中心、移出监控。
- 暂停商品禁用“立即采集”；已进入选品中心的商品禁用重复加入；“移出监控”保持可用。
- 该三点浮层约定覆盖 `mockup.html` 中早期“采集 / + 选品”行内按钮示例。

### 6.2 店铺监控

- 以店铺为一级信息。
- 店铺行可以展开已监控商品。
- 不显示“整店自动采集”类入口。
- 支持 Excel / CSV 导出。

### 6.3 选品中心

- 与单品监控保持同一表格视觉和数据口径。
- 操作为“采集”“移出”。
- 支持 Excel / CSV 导出。
- 手机区收起后，选品中心全宽显示。

## 7. 禁止自行变化

后续实现未经用户确认，不得：

- 改成深色主题。
- 引入紫色 AI 渐变、霓虹、玻璃拟态。
- 改成传统企业后台的大侧栏导航。
- 大面积使用品牌红背景。
- 将辅助文字重新降为 #999 / #AAA。
- 将正文或重要辅助文字缩小到 12px 以下。
- 将标题普遍改为 700/800 粗体。
- 改变“左手机 + 右工作区”的核心结构。
- 删除手机区收起 / 展开能力。
- 删除 Excel / CSV 导出入口。
- 将店铺监控改为整店自动采集。
- 未经确认新增复杂 AI、评分或预测模块。
