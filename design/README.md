# Design artifacts

本目录保存 **小红书选品工作台 V1 已确认设计基线**。

## 必须先读

后续任何 UI 开发或修改，按以下顺序读取：

1. `../prd.md` — 产品范围和功能。
2. `../DESIGN.md` — 基础视觉语言。
3. `visual-contract.md` — **用户已确认的项目级视觉与交互硬约束；优先级最高。**
4. `mockup.html` — 可交互核心页面设计稿。

未经用户明确确认，不得自行更换已确认风格或删除已确认交互。

## 设计稿

`mockup.html` 支持以下预览参数：

- `?view=single` — 单品监控
- `?view=single&export=1` — 单品监控 + 导出菜单
- `?view=shops` — 店铺监控
- `?view=selection` — 选品中心
- 页面中点击“收起手机 / 展开手机”可预览手机区折叠状态
